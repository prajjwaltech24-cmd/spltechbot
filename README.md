# SPL Techbot — Practical STEM, Robotics & AI Education for Future-Ready Students

SPL Techbot is an education-technology website built for a technology-learning partner providing STEM & Robotics labs, kits, structured curriculum, workshops, trained instructors, and consultation to private schools and educational institutions.

## Core Brand Positioning
- **Main Positioning**: "Practical STEM, Robotics & AI Education for Future-Ready Students."
- **Central Philosophy**: "Learn. Build. Experiment. Innovate."
- **Approach**: Understand &rarr; Explore &rarr; Build &rarr; Test &rarr; Improve &rarr; Innovate

## The Three Pillars: HTML + CSS + JavaScript Integration
1. **HTML5**: Semantic structure across 12 full-featured pages (Home, About, Services Hub, Robotics & AI Labs, STEM Labs, STEM Kits, Workshops, Trainer Support, School Consultation, Curriculum, FAQ, and Contact).
2. **CSS3**: Modern, sleek tech aesthetic with deep navy, electric blue, glassmorphism, responsive grid layouts, and elevation animations.
3. **Vanilla JavaScript**:
   - **Interactive STEM Lab Blueprint Calculator**: Real-time recalculation of workstations, hardware kits, capacity, and weekly sessions.
   - **15-Project Deep-Dive Modals**: Clickable prototypes revealing hardware bills, learning objectives, and industrial applications.
   - **Live Real-Time FAQ Search**: Instant question filtering and auto-expanding accordion matches.
   - **Interactive Form Confirmation**: Randomized inquiry reference numbers (`#NX-STEM-XXXX`) with instant verification banners.
   - **Dynamic Project Level Filtering**: Smooth scale and opacity transitions across beginner, intermediate, and advanced categories.

## Zero False Claims Policy
The site positions the company purely on vision, pedagogy, engineering curriculum, and institutional solutions without fake statistics, testimonials, awards, or false previous client claims.
